PORTFOLIO — BASIC DRAFT
=======================
Uses plain HTML, CSS and JavaScript.

TO OPEN
1. Extract the ZIP file.
2. Open index.html in a browser.


FUNCTIONS
The HTML IDs and JavaScript hooks are kept for mobile navigation, theme switching, active section navigation, project search and category filters, project detail dialogs, copy-email, scroll progress, back-to-top, reveal effects and front-end form validation. The contact form opens an email application; it does not send messages to a server.
